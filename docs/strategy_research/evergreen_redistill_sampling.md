# Evergreen 重新蒸餾:樣本定案(2026-07-27)

> **⚠ 本文的 EV31 方案已被 EV32 取代**(同日,經多角度設計交叉檢查 + 自行實測後修正)。
> EV31 修好了資料汙染、還原價、期間重疊三件事,但自己帶進兩個新缺陷:
> **(A)** 對照組「要求」前期漲 ≥25%,正例卻無此條件 → 兩組動能差 41 個百分點,
> 蒸餾必然把動能學成判別力;**(B)** 用「暴漲起點日」當 t0 = 給了實盤標記者永遠拿不到
> 的視角(起點日錨定正例 prior120 中位 −7.3%,站位日錨定 +3.7%,證明它系統性挑在低點)。
> 現行方案見 `src/quantlib/evergreen/ev32_station_sample.py`,下方 EV31 的診斷部分
> (三個原始問題、還原價、期間切分)全部仍然成立且被 EV32 承襲。

**使用者指示**:「你先決定好重新蒸餾用的樣本。」

## 一句話結論

**新樣本 = 210 檔暴漲 + 204 檔配對對照,期間 2008-01 ~ 2021-12,與標記/回測期
(2022-07 起)完全不重疊。** 舊的 224 檔不丟棄,**降級為驗證集**——其中 126 檔
(70 暴漲 + 56 對照)在乾淨資料上仍成立,消息材料 100% 已在庫、零額外成本。

清單:`var/out/evergreen_ev31_surge_samples.csv` / `..._control_samples.csv`
產生器:`src/quantlib/evergreen/ev31_resample.py`(可重跑,seed 固定 20260727)

## 為什麼要重選——三個問題,不是一個

| # | 問題 | 證據 | 嚴重度 |
|---|---|---|---|
| 1 | **資料汙染** | 舊 168 檔在乾淨資料上只剩 **42%** 成立:35% 漲幅根本不到門檻(價格資料本身錯)、23% 是除權息/減資的機械跳動被當成暴漲 | 高 |
| 2 | **選樣方法** | 用原始收盤價、把含公司行動的窗**整段丟棄**;水平線 60 交易日與下游標記任務問的「2-6 個月」不一致 | 中 |
| 3 | **蒸餾期 = 標記期** | 樣本期 2022-07~2025-06、標記月份 2022-07~2025-04、refit 窗 2023-07~2026-07 **全部重疊**,而哲學逐條引用具名個股當證據(常珵/系微/承業醫/大綜/鼎天/保銳/驊宏資/富野/立康/聯詠/達能/類比科/巨有/迅杰/8404/2755)與「關稅崩盤底部反彈」(2025-04) | **最高** |

**第 3 點為什麼最嚴重**:標記 Agent 被要求 PIT(只用 ≤ 標記日的資訊),但**它的判斷
框架本身已經知道那些月份的答案**。PIT 紀律管得住 Agent 的搜尋,管不住框架裡的
後見之明。這使得 2022-2026 的回測**在方法上不成立**,無論資料多乾淨。

驗證程式:`ev30_sample_recheck.py`(暴漲組 + 對照組全驗)。

## 設計決定逐條(每個數字都寫得出出處)

| 決定 | 值 | 理由 |
|---|---|---|
| 價格基準 | `prices.fetch_adjusted_panel` 還原價 | 專案鐵律:所有報酬計算走 canonical prices。能**穿過**除權息/減資正確量測,不必像舊版丟掉 23% 的樣本 |
| 水平線 | 未來 **120 交易日**內的最大報酬 | 對齊標記任務問的「未來 2-6 個月」。舊版 60 日與下游不一致——哲學學的是 3 個月的形態,卻被拿去預測 6 個月 |
| 門檻 | ≥ **80%** | 沿用舊版「大幅上漲」語義以維持可比。敏感度已量:50% → 13,369 事件、80% → 6,579、100% → 4,437、150% → 1,946 |
| 蒸餾期 | t0 ∈ [2008-01-01, 2021-12-31],且**前瞻窗須在 2022-07-01 前結束** | 與標記/回測期完全不重疊,根治第 3 個問題。起點 2008 是因為 tpex 資料 2007-07 才開始 |
| 去重 | 同檔 **120 交易日**冷卻 | 與前瞻窗同長,一段漲勢只取一個樣本。舊版冷卻 30 < 窗 60,會把同一波重複計入 |
| 標的 | **四碼普通股 + t0 當下已申報月營收** | 自查抓到舊抽樣混入 00633L/00655L(槓桿 ETF)、020010(ETN)、**70391/71540(權證)**、912398(TDR)——對這些做「它為什麼暴漲」的消息歸因毫無意義。判準非拍板數字:代碼形狀是台股慣例,月營收是營運公司的定義且 PIT 正確 |
| 流動性 | 當日**橫斷面 ADV20 三分位**,**只標記不過濾** | 絕對金額門檻在 2008 與 2021 意義不同,橫斷面分位自我正規化。哲學曾發現「純查無消息暴漲佔 12.5-37.5%,集中在低流通小型股」——濾掉就永遠驗證不了那條,留作維度反而能在乾淨資料上重測 |
| 抽樣 | **年 × 流動性層,每格 5 檔** | 舊樣本只涵蓋 3 年、約 1.5 個總經 regime,而哲學的第十道判別正是「宏觀 regime 時點」。分層後涵蓋金融海嘯、歐債、2015 貶值、2018 貿易戰、2020 疫情崩盤與噴出、2021 狂熱。只按年分層會讓 2008(1,063 事件)/2020(1,162)吃掉配額;只按層分層則失去 regime 覆蓋 |
| 對照組 | **配對式 hard negative**:同月 × 同產業 × 同流動性層,前 120 日漲 ≥25% 但前瞻最大 <20% | 舊版只有後兩個條件、無配對,對比裡混著年代與族群差異。配對後總經與族群被控制掉,對比才落在「個股本身有什麼不同」。實際配對品質:L1(同月+同業+同層)99 檔、L2(同月+同層)85、L3 16、L4 4 |
| 年代標籤 | `limit_era` = 7% / 10% | 台股漲跌幅 2015-06-01 由 7% 放寬到 10%(`engine.LIMIT_CHANGE_DATE`),是市場微結構斷點:同樣的再定價在 7% 下需更多天走完。標記期全在 10% era,故 10% 樣本與下游同構、7% 是外推。標記後可分開檢視,也可整層剔除而不必重抽 |

## 樣本輪廓

- **210 暴漲**(7% era 109 / 10% era 101);逐年 × 層各 5 檔,14 年 × 3 層
- **204 配對對照**(7% era 103 / 10% era 101)
- 漲幅中位 **+84%**、最大 +510%
- 涵蓋 **26 個產業**;前五:電子零組件 37、半導體 35、光電 19、電腦週邊 11、通信網路 11
- 流動性三層在兩個年代內皆均衡(各 33~37 檔)

## 舊樣本不丟——降級為驗證集

| 舊資產 | 乾淨資料重驗結果 | 新角色 |
|---|---|---|
| 168 暴漲 | 70 檔仍成立(42%) | **驗證集**(2022-2025,對新哲學是 OOS) |
| 56 對照 | **56 檔全數仍成立(100%)** | 驗證集 |
| ev27_news 消息材料 224 檔 | 外部新聞,與價格資料無關 → **完全乾淨** | 驗證用,零額外搜尋成本 |

對照組 100% 存活的原因:汙染機制是「製造假暴漲」,只會把偽形變成非偽形,不會反向。

**驗證怎麼做**:哲學從 2008-2021 蒸餾完成後,把這 126 檔的**僅 `pit == "pre_t0"` 的
消息材料**餵給標記 Agent,讓它盲判「這是會暴漲的還是偽形」,量準確率。這是舊哲學
**從來沒有做過**的 held-out 測試。紀律:驗證集只能用一次,用完若據以調整哲學,
它就變成訓練集。

## 未解:老年代的消息可得性(需實測,不可臆測)

粗探針(WebSearch 三關鍵字)對 2008 / 2016 / **2020** 的樣本都只回傳常青的個股
資訊頁,查不到當期新聞。但**這個探針不足以下結論**——舊那批 2022-2025 的歸因能
成功,靠的是多輪針對性查詢 + WebFetch + Wayback + Chrome,不是三個關鍵字。
MOPS open API 實測僅含近期公告(t187ap04_L 回 2026 年資料),歷史需走
公開資訊觀測站表單查詢。

**處理方式**:不預先砍掉任何年代。樣本已打 `limit_era` 標籤,**先跑小規模試跑**
(各年代抽數檔跑真實歸因流程),實測「查無 t0 前消息」比率,再決定是否剔除某一層。
若 7% era 確實不可行,剔除該層即可,無須重抽。

## 這樣做之後,回測才重新有效

蒸餾期 2008-2021 → 哲學 → 標記 2022-07 起 → 回測 2022-07 起。
哲學對回測期而言是**完全樣本外**,2022-2026 的回測數字才第一次具備方法上的效力。

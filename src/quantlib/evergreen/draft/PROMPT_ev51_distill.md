# 鐵律(違反任一條,整份產出作廢)

1. **禁止具名、禁止時代錨。** 輸出全文不得出現任何公司名稱、四位數字代碼、`19xx` / `20xx` 年份或具體月份、具名歷史事件(某次崩盤、某項政策、某場戰爭、某次疫情)、具名國際廠商、具名題材或產品世代名。要指涉宏觀環境,只能用**型態**(恐慌性系統下殺中、落底修復初期、平穩上行、高檔過熱、結構性空頭中的反彈段、低量盤整);要引用證據,只能引假名(`S037`)與統計表編號;要指涉時間,只能用相對交易日 offset、「下 N 季」或密封期別碼。
